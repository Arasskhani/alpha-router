1. Executive summary

Alpha Router was assessed as if never previously hardened. The stack has meaningful defenses (non-root app container, Redis auth, docs lockdown, SSRF defaults, broker token checks, media/chat ownership for normal users). Residual risk remains concentrated in architecture (Docker socket), authz escalation, dual browser auth, and production soft-fail / exposure.

5. Detailed findings and fixes

Critical · F-01 · Docker socket on sandbox-broker

SandboxHost RCE class

Location

docker-compose.yml (sandbox-broker volume), backend/app/sandbox_broker.py

Finding

The broker mounts host /var/run/docker.sock and runs Docker CLI with a hardcoded execute policy. Auth is a shared bearer token. Compromising the broker process or stealing the token yields host Docker control (privileged containers, host FS mounts, etc.).

Evidence

Live inspect: sock RW mount; 8081 unpublished; alpha has no sock; execute missing/wrong token → 401. Broker Config.User empty.

Impact

Full host compromise class — highest privilege surface in the stack.

Fix recommendation
  • Keep broker unpublished; isolate on a dedicated host/VM; rotate SANDBOX_BROKER_TOKEN.
  • Prefer rootless Docker / gVisor / Firecracker / remote job runner without host sock if feasible.
  • Run broker as non-root (see F-10); monitor broker auth failures; never expose 8081.

High · F-15 · Users admin can grant Super Admin

Privilege escalation

Location

backend/app/api/admin.py (PATCH /users/{id}, bulk roles), user_role_service.py, rbac.py

Finding

Role updates require only require_users_write. There is demotion protection for the last full admin, but no promotion gate preventing assignment of super_admin or an equivalent full-menu set.

Impact

Horizontal privilege escalation: Users administrator → full platform Super Admin (docs, secrets, auth config, etc.).

Fix recommendation
  • Require Super Admin to grant/remove super_admin and global-equivalent role bundles.
  • Enforce “cannot assign roles above actor privilege” on all role PATCH/bulk endpoints.
  • Add regression tests for Users-admin attempting Super Admin assignment → 403.

High · F-02 · Production guard soft-fail

Location

backend/app/main.py production guard; runtime PRODUCTION_GUARD_MODE=warning + ENVIRONMENT=production

Finding

Production is labeled correctly, but insecure configuration only warns and continues booting.

Evidence

Settings probe: environment=production, production_guard_mode=warning; service is up.

Fix recommendation
  • Set PRODUCTION_GUARD_MODE=hard-fail after a secret/config checklist.
  • Use warning mode only for a short, tracked migration window.

High · F-03 · Legacy Bearer bypasses CSRF

Location

backend/app/api/deps.py, csrf_protection.py, auth.py, settings

Finding

Cookie session + CSRF are enabled, but allow_legacy_bearer_auth=True. CSRF middleware skips checks when the session cookie is absent. A Bearer JWT (still returned by login) can mutate /api/* without CSRF.

Evidence

Runtime: allow_legacy_bearer_auth=True, enable_csrf=True.

Fix recommendation
  • Disable legacy Bearer for browser clients after soak (ALLOW_LEGACY_BEARER_AUTH=false).
  • Stop returning access_token in SPA login JSON; keep /v1 on API keys only.
  • Retain CSRF double-submit for cookie session mutating routes.

High · F-04 · App bound to all interfaces on :8080

Location

docker-compose.yml alpha ports; live inspect 0.0.0.0:8080 / :::8080

Finding

Data planes bind to localhost, but the HTTP app is published on all interfaces. HSTS disabled; no TLS terminator verified.

Fix recommendation
  • Publish as 127.0.0.1:8080:8080 behind a TLS reverse proxy, or enforce host firewall + TLS edge.
  • Enable HSTS only after HTTPS is guaranteed end-to-end.

Medium · F-05 · Redis / login rate-limit fail-open

Location

backend/app/services/rate_limit.py

Finding

Redis is authenticated live (good). On Redis errors, limits fall back to per-worker memory counters, including login.

Fix recommendation
  • Fail-closed (or stricter local limit) specifically for login.
  • Alert on redis_fallback observability counters.

Medium · F-06 · CSP Report-Only only

Evidence

Live headers: Report-Only CSP present; enforcing CSP absent.

Fix recommendation
  • Collect violations, then enforce CSP.
  • Enable HSTS only with HTTPS (paired with F-04 / F-23).

Medium · F-07 · SSRF kill-switches

Location

ssrf_guard.py, config flags

Finding

Defaults are safe (private ranges blocked, DNS pinning on). Enabling private ranges or disabling pinning reopens internal reachability / rebinding.

Fix recommendation
  • Keep production defaults; require dual approval to change flags; alert on drift.

Medium · F-08 · Plaintext decrypt fallback

Location

backend/app/services/secret_crypto.py decrypt_secret

Finding

Non-Fernet values returned as plaintext; undecryptable tokens returned as-is (migration UX).

Fix recommendation
  • Confirm re-encryption migration complete; reject plaintext in production after cutover.
  • Fail closed on undecryptable ciphertext rather than returning raw DB bytes.

Medium · F-09 · Private Mode client confidentiality

Finding

Confidentiality depends on the browser client. Persist flags / shared machines can leave local transcripts and IndexedDB blobs.

Fix recommendation
  • Wipe private stores on logout by default; warn on shared devices; avoid persist on kiosks.

Medium · F-10 · Broker without explicit non-root USER

Evidence

Inspect: sandbox-broker Config.User empty while holding docker.sock.

Fix recommendation
  • Run broker as non-root where Docker API access still works; tighten socket group permissions.

Medium · F-16 · CORS always allows localhost with credentials

Location

backend/app/main.py CORSMiddleware allow_origins

Evidence

Origin: http://localhost:8080 → ACAO + Allow-Credentials; evil origin gets no ACAO.

Fix recommendation
  • In production, allow only FRONTEND_URL (explicit allowlist).
  • Include localhost origins only when ENVIRONMENT=development.

Medium · F-17 · OIDC redirect_uri not pinned

Location

backend/app/services/oidc.py, auth/authentication APIs

Finding

Redirect URI validation checks shape/HTTPS but does not pin to this app’s callback path under API_PUBLIC_URL.

Fix recommendation
  • Pin to {API_PUBLIC_URL}/api/auth/keycloak/callback (or strict allowlist).
  • Validate on save and on login/callback.

Medium · F-18 · Auth-admin IdP URL / session mint blast radius

Finding

Authentication-write admins can set IdP server_url/secrets. JWKS/token calls do not go through SSRF guard. A rogue IdP can mint identities into Alpha Router.

Fix recommendation
  • Gate Keycloak/LDAP writes to Super Admin (or dual-control).
  • Allowlist IdP hosts; route fetches through SSRF controls; pin issuer.

Medium · F-19 · LDAP plaintext bind fallback

Location

backend/app/services/ldap_auth.py

Finding

On port 389, client may fall back to plaintext bind after STARTTLS failure; untrusted cert mode also exists.

Fix recommendation
  • Fail closed unless LDAPS or successful STARTTLS in production.
  • Default trust_untrusted_cert=false; surface strong UI warnings.

Medium · F-20 · Budget month-rollover reservation gap

Location

budget_service.py period reset vs budget_reservation_service.py holds

Finding

Concurrent reserve/settle locking looks solid, but month rollover can reset used totals without consistently clearing open reservations/holds.

Fix recommendation
  • On period change: expire/settle open holds first, or attribute settlement to reservation period.
  • Keep budget_reserved_usd consistent with reservation rows after rollover.

Medium · F-21 · Provider errors echoed to clients/logs APIs

Location

proxy_service.py, images.py, logs APIs, SMTP error paths

Finding

Raw upstream/provider exception text (truncated) can reach end users and admin/user log surfaces.

Fix recommendation
  • Return stable client error codes; keep full detail in server logs only.
  • Store redacted error_code in DB, not raw provider bodies.

Low · F-11 · Gateway master key non-constant-time compare

Location

backend/app/api/gateway.py

Fix recommendation
  • Compare with hmac.compare_digest (as broker token already does).

Low · F-12 · Masked secrets show last 4 characters

Fix recommendation
  • Mask without decrypting tails; show length/fingerprint metadata only.

Low · F-13 · ChatCodeBlock dangerouslySetInnerHTML

Location

frontend/src/components/chat/ChatCodeBlock.tsx (Markdown itself has no rehype-raw — positive)

Fix recommendation
  • Enforce CSP (F-06); pin/review highlight.js; prefer safer rendering where possible.

Low · F-22 · Gateway lacks request rate limits

Finding

/v1 authenticates then relies mainly on budget/credit — no per-key/IP request rate limit observed.

Fix recommendation
  • Add Redis per-key and per-IP limits; stricter defaults for master key; concurrency caps.

Low · F-23 · HSTS trusts X-Forwarded-Proto

Fix recommendation
  • Trust forwarded proto only from known reverse proxies; strip/overwrite at the edge.

Low · F-25 · API-looking path with ../ falls through to SPA HTML

Evidence

Request to /api/chat/media/../../../etc/passwd/file returned 200 text/html SPA shell (~692 bytes), not a filesystem read. After client/server normalization the path no longer starts with api/, so SPA fallback serves index.html. Dist containment prevents arbitrary file read.

Fix recommendation
  • Reject requests whose raw path contains .. before routing, or always return JSON 404 for normalized escapes from /api.
  • Keep serving only files under frontend dist (already present).

Informational · F-14 · Users-menu cross-user media read (by design)

Accounts with Users menu can read any user’s media via shared authorization helper. Treat as high-trust capability, not a normal-user IDOR.

Fix recommendation
  • Audit role assignments; log cross-user media access; prefer just-in-time elevation.

Informational · F-24 · LDAP bridge powerful once token known

Bridge fail-closes without token and defaults to loopback bind (good). With a valid token it accepts client-supplied LDAP config/passwords — high blast radius by design.

Fix recommendation
  • Pin bridge config server-side; rate-limit; keep loopback + firewall; rotate token; prefer native LDAPS/Keycloak federation long-term.

6. Controls that held

  • Alpha Router: non-root, read-only rootfs, CapDrop ALL, no-new-privileges, no docker.sock.
  • Broker: unpublished; execute auth required; policy hardcodes image/network; extras forbidden.
  • Insecure code subprocess disabled; SSRF private ranges off; DNS pinning on.
  • Gateway anonymous/bad key → 401; gateway body.user impersonation appears blocked.
  • Evil Origin on login → 403; admin/ops/logs unauthenticated → 401.
  • OpenAPI/docs locked for anonymous callers.
  • Redis requires authentication.
  • Custom (non-default) SECRET_KEY / gateway master; data encryption key set; broker token length ≥ 32.
  • Minimal health payload; body-size middleware present; ZIP export caps / filename sanitize look solid.
  • No confirmed cross-user IDOR for normal users on chat sessions/messages/media.
  • Markdown without rehype-raw; URL policy hardening; JWT localStorage keys cleared on logout paths.
  • OIDC PKCE/state/nonce/one-time exchange design looks sound (redirect pinning aside).
  • SPA dist path containment blocks arbitrary file read for traversal candidates.

7. Remediation priority (advisory — not performed)

  1. Immediate: F-15 (RBAC promotion), F-02 (hard-fail guard), F-03 (disable legacy Bearer for browsers).
  2. Short term: F-04/F-16/F-06/F-23 (network bind, CORS, CSP/HSTS behind proxy).
  3. Auth federation: F-17, F-18, F-19, F-24.
  4. Architecture: F-01, F-10 (broker/docker.sock isolation).
  5. Hardening polish: F-05, F-08, F-20, F-21, F-11, F-12, F-13, F-22, F-25, F-09.

No remediation was applied in this engagement. Implement fixes only after explicit approval in a separate change window.

8. Limitations

  • Authenticated dual-user browser matrix (full CSRF cookie + IDOR with two disposable accounts) was not exhaustively executed end-to-end in UI; ownership was verified primarily via code + unauth probes.
  • External OpenRouter / corporate LDAP / remote Keycloak were not attacked.
  • No destructive load tests or Docker-socket exploitation beyond architecture documentation.
  • Findings reflect the observed local Compose state on 2026-07-20.
  • This report contains zero secret values by design.
